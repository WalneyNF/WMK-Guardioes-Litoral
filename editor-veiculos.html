📘 Orientações e limitações ⠿

1. Selecione um veículo, altere os campos e clique em Aplicar alterações. Depois clique em Salvar no navegador.

2. Volte ao jogo e recarregue a página para aplicar o preset. Use Exportar JSON para compartilhar os valores; a importação exige o mesmo formato.

3. Arraste a barra dos painéis e redimensione pela borda inferior direita. As posições são lembradas no navegador (desktop).

Limitações: preview é uma ilustração 2D, não modelo GLB. IDs, tipos de modelo e quantidade de veículos ficam fixos nesta etapa. O projeto não grava arquivos no GitHub automaticamente.
